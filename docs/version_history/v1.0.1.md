## 2. Release Scope & Summary of Changes

### Fixed
- **Dynamic Profile Submissions Metric (`OA-M1-F2`)**:
  - Implemented `getLiveSubmissionMetrics()` in `src/lib/services/profile.ts` to query authentic records from `drive_links` directly where `uploader_user_id = userId` and `is_removed = false`.
  - Replaced the stale seed database counter (`submission_count: 5`) with dynamic breakdown: `1 submission (3 indexed works)`.

### Refactored
- **Display Card & Skeleton UI (`OA-M2-F5`)**:
  - Removed legacy top `SYSTEM HEADER: OurArchive Emergency Mirror (Temporary Read-Only Library)` bar from `src/components/cards/DisplayCard.tsx` and `src/components/ui/SkeletonCard.tsx`.
  - Repositioned document format indicators (`PDF Mirror`, `Doc Mirror`, `📁 Collection`) neatly beside the rating badge in the title row.

### Added
- **SFW / NSFW Catalog Classification (`OA-M2-F6`)**:
  - Added a visible content classification selector (`🟢 SFW (Safe for Work)` vs `🔴 NSFW (18+ / Mature)`) to `UploadModal.tsx`.
  - Automatically aligns content rating and appends `sfw` or `nsfw` tag to metadata, cascading down to all unpacked child works from collection folders.
- **SFW / NSFW Search Filters (`OA-M2-F3`)**:
  - Added interactive filter pills (`[All Works]`, `[🟢 SFW Only]`, `[🔴 NSFW (18+)]`) to `SearchSection.tsx`.
  - Updated `/api/search` route to filter dynamically by rating groups and classification tags.
- **Interactive Folder Ingestion Limits Guide (`OA-M2-F6`)**:
  - Added `ℹ️ Folder Limits & Guide` header button in `UploadModal.tsx` that replaces the modal form with a clear visual hierarchy guide (`//contributed link`, `.//folder 1`, `..//folder inside folder 1`).
  - Outlined system limits: Max 4 nesting depth, max 30 subfolders traversed, max 100 readable files, view-only requirement.
- **AI Policy & Transparency Disclaimer (`OA-M3-F4`)**:
  - Added Pillar 6 to `src/app/disclaimers/page.tsx` in approachable community language:
    - Planned and directed by developer `Oeubx`.
    - Built using Google's Antigravity tool with Gemini 3.8 Flash as an engineering assistant.
    - Zero AI running on the live production website.
    - Zero reading, parsing, or training on creators' stories.
    - Simple deterministic rule-based MIME and extension safety checks without AI text evaluation.
- **Project Repository Hyperlink (`OA-M0-F0`)**:
  - Configured `NEXT_PUBLIC_PROJECT_REPO` in `src/lib/config.ts` and `.env.example`.
  - Added `📦 Project Repo` hyperlink in global footer "Reach Out & Connect" directing visitors to `https://github.com/Oeubx/OurArchive`.

### Changed
- **Terminology Rebranding (`OA-M3-F4`)**:
  - Replaced "Emergency Service" with "TEMPORARY PROJECT" across Homepage hero badge, global emergency notice banner, footer, and community disclaimers.
