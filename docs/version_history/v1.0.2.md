## 2. Release Scope & Summary of Changes

### Added

- **Deterministic First-Page Metadata Parser & Scan Endpoint (`OA-M2-F2`)**:
  - Implemented a platform-agnostic, non-AI deterministic regex parser in `src/lib/services/metadata-parser.ts` that extracts title, author, rating, categories, archive warnings, characters, relationships, word count, status, and language directly from fanwork document page 1.
  - Includes a deterministic SFW/NSFW classification engine and a non-destructive plain-text fallback for unstructured documents.
  - Created ephemeral in-memory page-1 streaming API endpoint at `src/app/api/links/scan-metadata/route.ts` — zero file storage, fully compliant with the Read-Only / Zero-Download principle.
  - Added automated unit tests in `src/lib/services/__tests__/metadata-parser.test.ts` verifying catalog extraction and classification accuracy.

- **Dynamic Debounced Auto-Search & Multi-Facet Filtering (`OA-M2-F3`)**:
  - Added a full multi-facet filter drawer to `src/components/search/SearchSection.tsx` with controls for Category (Gen, F/F, F/M, M/M, Multi, Other), Rating, Archive Warning, Completion Status, Character search, and Word Count range.
  - Implemented 350ms debounced auto-search with `AbortController` cancellation to eliminate database query congestion.
  - Updated `src/app/api/search/route.ts` to filter dynamically by all new metadata dimensions using GIN array containment operators.
  - Updated `src/components/cards/DisplayCard.tsx` to render category pills, warning badges, character tags, and completion status indicators.

- **Manual Metadata Scan in Contributor & Admin Upload Modals (`OA-M2-F6`)**:
  - Added a `Scan Metadata` button and granular categorization controls (category, warnings, characters, relationships, completion status, language) to `src/components/upload/UploadModal.tsx` and `src/components/upload/AssistedIntakeModal.tsx`.
  - Implemented verification-triggered metadata scan and admin submit lock in `src/components/admin/AdminDirectUploadModal.tsx` — submit is locked until metadata scan is confirmed.
  - Updated submission API routes (`/api/links/submit`, `/api/assisted-intake`) to persist all granular fanwork catalog fields.

- **Granular Fanwork Metadata Schema & Collection Purge Cascades (`OA-M1-F4`)**:
  - Extended `public.link_metadata` with six new columns: `categories TEXT[]`, `characters TEXT[]`, `warnings TEXT[]`, `relationships TEXT[]`, `is_complete BOOLEAN`, `language VARCHAR(50)`.
  - Added 4 GIN indexes for fast array filtering and 1 B-tree index on `is_complete`.
  - Updated `vw_public_search_feed` and `vw_admin_triage_feed` to surface all granular metadata fields.
  - Implemented collection folder purge cascades in takedown and admin-action services to prevent orphaned child fanworks during removal.
  - New migration file: `supabase/migrations/20261114_000010_granular_metadata_and_filters.sql`.

- **Deterministic Catalog Scanning Disclosure (`OA-M3-F4`)**:
  - Added a Pillar 6 subsection to `src/app/disclaimers/page.tsx` disclosing the ephemeral first-page fanwork catalog metadata extraction process.
  - Documented non-AI regex scanning, zero-download processing, and zero story content retention.
  - Updated `docs/backlogs/module-2-drive-upload-search/drive_link_processing_spec.md` with scanning specification.

### Fixed

- **Database View Cascade on Schema Migration (`OA-M1-F4`)**:
  - Added `DROP VIEW IF EXISTS CASCADE` for `vw_public_search_feed` and `vw_admin_triage_feed` before column additions in the migration file, resolving PostgreSQL error `42P16` during view recreation.

## 3. Database Migrations Required (`v1.0.2`)

> [!IMPORTANT]
> **1 new mandatory database migration must be applied** in Supabase before deploying `v1.0.2` to production.

### Migration File

```
supabase/migrations/20261114_000010_granular_metadata_and_filters.sql
```

Run this in the **Supabase SQL Editor** (or via Supabase CLI `supabase db push`):

```sql
-- 1. Extend link_metadata with granular catalog columns
ALTER TABLE public.link_metadata
ADD COLUMN IF NOT EXISTS categories TEXT[] DEFAULT '{}'::TEXT[],
ADD COLUMN IF NOT EXISTS characters TEXT[] DEFAULT '{}'::TEXT[],
ADD COLUMN IF NOT EXISTS warnings TEXT[] DEFAULT '{}'::TEXT[],
ADD COLUMN IF NOT EXISTS relationships TEXT[] DEFAULT '{}'::TEXT[],
ADD COLUMN IF NOT EXISTS is_complete BOOLEAN DEFAULT FALSE,
ADD COLUMN IF NOT EXISTS language VARCHAR(50) DEFAULT 'English';

-- 2. GIN Indexes for Fast Array Inclusions & Filtering
CREATE INDEX IF NOT EXISTS idx_link_metadata_categories
ON public.link_metadata USING GIN (categories);

CREATE INDEX IF NOT EXISTS idx_link_metadata_characters
ON public.link_metadata USING GIN (characters);

CREATE INDEX IF NOT EXISTS idx_link_metadata_warnings
ON public.link_metadata USING GIN (warnings);

CREATE INDEX IF NOT EXISTS idx_link_metadata_relationships
ON public.link_metadata USING GIN (relationships);

CREATE INDEX IF NOT EXISTS idx_link_metadata_is_complete
ON public.link_metadata (is_complete);

-- 3. Drop existing views to allow reordering and adding new columns cleanly
DROP VIEW IF EXISTS public.vw_public_search_feed CASCADE;
DROP VIEW IF EXISTS public.vw_admin_triage_feed CASCADE;

-- 4. Recreate vw_public_search_feed with Granular Metadata
CREATE VIEW public.vw_public_search_feed
WITH (security_invoker = true) AS
SELECT
    dl.id AS work_id,
    dl.upload_mode,
    dl.created_at AS uploaded_at,
    lm.title,
    lm.author_name,
    lm.fandom,
    lm.pairing,
    lm.rating,
    lm.word_count,
    lm.summary,
    lm.tags,
    lm.mime_type,
    COALESCE(lm.categories, '{}'::TEXT[]) AS categories,
    COALESCE(lm.characters, '{}'::TEXT[]) AS characters,
    COALESCE(lm.warnings, '{}'::TEXT[]) AS warnings,
    COALESCE(lm.relationships, '{}'::TEXT[]) AS relationships,
    COALESCE(lm.is_complete, FALSE) AS is_complete,
    COALESCE(lm.language, 'English') AS language,
    CASE
        WHEN lm.is_owner_masked THEN
            regexp_replace(lm.drive_owner_email, '(?<=^.{2}).*?(?=@)', '***')
        ELSE lm.drive_owner_name
    END AS display_drive_owner,
    COALESCE(lv.verification_badge, 'UNVERIFIED') AS verification_badge,
    lv.admin_verified_at,
    COALESCE(lv.automated_risk_score, 0) AS automated_risk_score,
    encode(digest(dl.drive_url, 'sha256'), 'hex') AS path_reveal_token
FROM public.drive_links dl
JOIN public.link_metadata lm ON dl.id = lm.link_id
LEFT JOIN public.link_verifications lv ON dl.id = lv.link_id
WHERE dl.verification_status = 'verified'
  AND dl.is_hidden = FALSE
  AND dl.is_removed = FALSE;

-- 5. Recreate vw_admin_triage_feed with Granular Metadata
CREATE VIEW public.vw_admin_triage_feed
WITH (security_invoker = true) AS
SELECT
    dl.id AS link_id,
    dl.drive_url,
    dl.google_file_id,
    dl.upload_mode,
    dl.verification_status,
    dl.is_hidden,
    dl.is_removed,
    dl.created_at,
    dl.updated_at,
    lm.title,
    lm.author_name,
    lm.fandom,
    lm.pairing,
    lm.rating,
    lm.word_count,
    lm.summary,
    lm.tags,
    lm.canonical_source_url,
    lm.file_name,
    lm.mime_type,
    lm.file_size_bytes,
    lm.drive_owner_name,
    lm.drive_owner_email,
    lm.is_owner_masked,
    COALESCE(lm.categories, '{}'::TEXT[]) AS categories,
    COALESCE(lm.characters, '{}'::TEXT[]) AS characters,
    COALESCE(lm.warnings, '{}'::TEXT[]) AS warnings,
    COALESCE(lm.relationships, '{}'::TEXT[]) AS relationships,
    COALESCE(lm.is_complete, FALSE) AS is_complete,
    COALESCE(lm.language, 'English') AS language,
    lv.id AS verification_id,
    COALESCE(lv.automated_risk_score, 0) AS automated_risk_score,
    COALESCE(lv.automated_flags, '[]'::JSONB) AS automated_flags,
    COALESCE(lv.scanner_passed, FALSE) AS scanner_passed,
    lv.admin_verified_by,
    lv.admin_verified_at,
    lv.admin_notes,
    COALESCE(lv.verification_badge, 'UNVERIFIED') AS verification_badge,
    up.display_name AS uploader_display_name,
    up.role AS uploader_role,
    COALESCE(up.is_banned, FALSE) AS uploader_is_banned,
    COALESCE(up.submission_count, 0) AS uploader_submission_count
FROM public.drive_links dl
LEFT JOIN public.link_metadata lm ON dl.id = lm.link_id
LEFT JOIN public.link_verifications lv ON dl.id = lv.link_id
LEFT JOIN public.user_profiles up ON dl.uploader_user_id = up.id
WHERE dl.is_removed = FALSE;
```
