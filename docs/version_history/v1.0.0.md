## 2. Module Scope (`OA-M0` – `OA-M3`)

### Module 0 — Infrastructure, Telemetry & Progressive Delivery (`OA-M0`)
- Next.js 14 App Router, TypeScript, Tailwind CSS (light/dark/warm themes), and `pnpm` workspace setup.
- Vercel serverless configuration (`vercel.json`) and Edge middleware (`src/middleware.ts`) with rate limiting and security headers.
- `/api/health` endpoint reporting Supabase Auth connectivity and `version: "1.0.0"`.
- GitHub Actions CI gate (`.github/workflows/ci.yml`) enforcing branch flow, Markdown link integrity, absolute-path blocking, `tsc --noEmit`, and `next lint`.

### Module 1 — Authentication, Profiles, RBAC & Database (`OA-M1`)
- Email/password sign-up & sign-in, OAuth callback, email verification, password visibility toggle, and community disclaimer interstitial.
- Multi-role RBAC (`reader`, `contributor`, `verifier`, `admin`) with server-side JWT/profile claim verification, `/admin` & `/manage` route guards, and anti-role-elevation triggers.
- `/profile` account page and `/feedback` signed-in community feedback portal.

### Module 2 — Drive Ingestion, Search & Distraction-Free Reader (`OA-M2`)
- Canonical Google Drive URL validator, segmented link input, authenticated contributor upload (`/contribute`), and assisted public intake (`/api/assisted-intake`).
- `/search` full-text discovery with `DisplayCard` grid, configurable page sizes, skeleton loaders, and masked Drive URL reveal modal (`/api/links/reveal`).
- Ephemeral `/reader/[id]` sandbox with in-memory Drive PDF-to-HTML extraction (`unpdf`), coordinate-aware spacing, zero-dependency HTML sanitization, 3-way view mode switcher, flash-free light/warm/dark theme sync, recursive Drive subfolder ToC, masked URL IDs, and Supabase-backed bookmarks & PDF checkpoints.

### Module 3 — Verification, Safety, Audit, Takedowns & Compliance (`OA-M3`)
- Two-tier automated threat scanner and auto-quarantine state machine.
- `/manage` & `/admin` 6-action triage suite, pre-approval `LinkInspectionModal`, `VerifierRequestsModal`, mobile card layout, and Supabase Realtime updates.
- Persistent purge tombstones and lifecycle audit history (`/api/admin/audit`) with CSV/PDF export.
- Zero-barrier `/takedown` protocol (Supabase queue with ownership proof, prefilled reader takedowns, screenshot guidance, and direct email copy modal with 24h SLA).
- `/disclaimers`, `/about-developer`, and global `EmergencyNoticeBanner`.
